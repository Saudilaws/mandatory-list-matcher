# Mandatory List Matcher v0.3

نسخة محلية مستقلة لفحص بنود الإدارات مقابل القائمة الإلزامية المرفوعة بتاريخ 2026-09-17.

## البيانات المضمنة
- 1,749 منتجًا
- 164 قطاعًا
- الحقول: رمز اعتماد، الاسم العربي، الاسم الإنجليزي، القطاع، الوصف، الحد الأدنى للمحتوى المحلي، تاريخ التطبيق، الملاحظات
- لا توجد أكواد مكررة في ملف المصدر.
- توجد أسماء رسمية مكررة بأكواد مختلفة؛ المحرك يعرض الغموض بدل اختيار رمز اعتباطي.

## ما أضيف في v0.3
- قاموس مفردات ميدانية عربي/إنجليزي وكتابة صوتية شائعة في المشتريات.
- فهم سياقي للاختصارات LV / MV / HV / DC وقراءة kV في سياق الكابلات والمحولات.
- مفردات كهربائية مثل ترانس، بريكر، MCCB، ACB، GCB، سويتش بورد، DB.
- مفردات HVAC مثل دكت، AHU، سبلت، باكدج، شفاط، اير كمبروسر.
- أنواع الصمامات مع حواجز ضد المطابقات الطبية الكاذبة.
- PVC / HDPE وأنواع وصلات الأنابيب (كوع، كوبلن، كاب).
- مفردات الدهانات والتنظيف والزجاج والخزانات والزيوت والشحوم.
- كشف تضارب أكثر صرامة، مع إبقاء الحالات الغامضة في "يحتاج مراجعة" بدل إجبار تطابق.

## سياسة القرار
المحرك لا يعتبر التشابه اللغوي وحده دليلًا كافيًا. يستخدم الاسم الرسمي والوصف والقطاع والمرادفات والسياق والمواصفات، ويخفض الدرجة عند وجود تعارض أو عندما يكون المرشح أضيق من البند.

## التشغيل
افتح `index.html` مباشرة في متصفح حديث. لا يحتاج خادمًا أو اتصال إنترنت.

## الاختبارات
راجع `TEST-REPORT.txt` وملفات JSON الخاصة بمجموعات الاختبار داخل الحزمة.

## مهم
نتائج الاختبارات الصناعية قوية، لكنها لا تساوي إثبات نسبة دقة ميدانية على جميع صياغات الإدارات. الاعتماد الإنتاجي النهائي يتطلب Corpus حقيقيًا من بنود الإدارات مصنفًا يدويًا من مختصين، ثم قياس Precision / Recall / False Positive Rate عليه.
