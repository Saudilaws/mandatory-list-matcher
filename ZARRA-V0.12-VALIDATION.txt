Important limitation:
This package does NOT claim byte-for-byte/token-for-token parity with the official Python Model2Vec implementation. The model is standard embeddings-only I8 format and mean-pooling is appropriate for that format, but tokenizer.json contains a Precompiled normalizer. The browser runtime currently approximates that normalizer with NFKC. Until an independent official-runtime parity oracle is available, Zarra remains retrieval-only by design.
